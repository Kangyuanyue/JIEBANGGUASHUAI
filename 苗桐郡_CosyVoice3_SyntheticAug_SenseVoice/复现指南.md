# 复现指南

## 1. 环境划分

本实验使用两个隔离环境，避免 CosyVoice 与 FunASR/SpeechBrain 的依赖冲突。

### TTS环境

- Python 3.10。
- 安装与本机CUDA匹配的PyTorch和Torchaudio。
- 克隆CosyVoice并固定到已验证提交：

```bash
git clone --recursive https://github.com/QwenAudio/CosyVoice.git third_party/CosyVoice
git -C third_party/CosyVoice checkout 074ca6dc9e80a2f424f1f74b48bdd7d3fea531cc
python -m pip install -r requirements-tts.txt
python -m pip install -r third_party/CosyVoice/requirements.txt
```

下载`FunAudioLLM/Fun-CosyVoice3-0.5B-2512`到`models/Fun-CosyVoice3-0.5B/`。TTS模型只在训练数据生成阶段使用，最终ASR推理不加载TTS模型。

### ASR/TSE环境

- Python 3.12。
- 安装与本机CUDA匹配的PyTorch和Torchaudio。

```bash
python -m pip install -r requirements-asr.txt
```

`configs/environment_reference.json`记录了实际验证过的关键版本。PyTorch不在requirements中固定，因为安装命令取决于CUDA版本。

## 2. 数据准备

个人录音清单、提示音频和无人声噪声不随仓库分发。字段格式见`examples/manifest_examples.json`。

```bash
python programs/prepare_tts_texts.py --recording-list data/recording_list.csv --audio-root data/personal_audio --out data/personal.jsonl --summary results/personal_summary.json --seed 42
python programs/validate_training_boundaries.py --manifest data/personal.jsonl --require-audio --out results/personal_boundary.json
python programs/prepare_stage3_corpus.py --personal data/personal.jsonl --generation-config configs/stage3_text_generation.json --speaker-config configs/speakers.local.json --text-out data/stage3_texts.jsonl --tts-out data/stage3_tts.jsonl --audio-dir data/stage3_clean --summary results/stage3_summary.json
```

`configs/speakers.local.json`由复现者在本机创建，只填写有权使用的参考音频，不提交个人音频或个人声纹。

## 3. TTS合成与筛选

```bash
python programs/run_local_tts.py --manifest data/stage3_tts.jsonl --model models/Fun-CosyVoice3-0.5B --report results/tts_report.jsonl --resume
python programs/build_asr_eval_manifest.py --synthesis-report results/tts_report.jsonl --out data/tts_asr_eval.jsonl
python programs/run_manifest_asr.py --manifest data/tts_asr_eval.jsonl --model iic/SenseVoiceSmall --device cuda:0 --out runs/tts_asr
python programs/validate_tts_corpus.py --synthesis-report results/tts_report.jsonl --asr-pred runs/tts_asr/predictions.jsonl --out results/tts_quality.json --details results/tts_quality_details.jsonl
```

使用SenseVoice对`data/tts_asr_eval.jsonl`回译后，将预测传给质量筛选程序。最终只保留通过CER、时长、静音率、削波率和声纹相似度检查的样本。

## 4. 混音和训练

```bash
python programs/build_tts_mixtures.py --manifest data/stage3_training_pass.jsonl --tts-manifest data/stage3_tts.jsonl --config configs/stage4_mixtures.json --noise-dir data/non_speech_noise --out data/stage4
python programs/prepare_stage5a1_curriculum.py --real-manifest data/real_train.jsonl --synthetic-manifest data/stage3_training_pass.jsonl --noise-wav-dir data/non_speech_noise --config configs/stage5a1_curriculum.json --out data/curriculum
python programs/train_stage5a_sensevoice.py --train-manifest data/curriculum/synthetic_augmented_train.jsonl --config configs/stage5a1_curriculum.json --route real_plus_synthetic --out runs/sensevoice_synthetic_augmented
```

普通ASR只使用干净音频和无人声噪声增强音频。强重叠混合信号只作为目标说话人提取实验数据，不能直接配目标文本训练普通ASR。

## 5. 分离和独立评测

```bash
python programs/run_stage6_separation.py --manifest data/evaluation.jsonl --config configs/stage6_datasetA.json --out runs/separation
python programs/run_stage6_asr.py --separation-dir runs/separation --config configs/stage6_datasetA.json --out runs/asr
python programs/evaluate_stage6_locked.py --dataset data/evaluation.jsonl --separation-dir runs/separation --asr-dir runs/asr --checkpoint runs/sensevoice_synthetic_augmented/checkpoint --selector-model runs/selector/selector_model.joblib --selector-config runs/selector/selector_config.json --lexicon-manifest data/train_lexicon.jsonl --reject-config configs/reject_balanced.yaml --known-labels-manifest data/train_lexicon.jsonl --out runs/evaluation
```

独立测试前必须冻结checkpoint、选择器和拒识阈值。测试结果只能用于报告，不能反向修改训练数据、模型或阈值。

## 6. 快速自检

```bash

python programs/train_stage5a_sensevoice.py --help
python programs/run_stage6_separation.py --help
python programs/evaluate_stage6_locked.py --help
```
