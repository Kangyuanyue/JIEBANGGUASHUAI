# 算法架构

## 1. 合成语料

从智能家居设备、房间、动作、模式、温度和百分比槽位组合指令文本。固定随机种子后按模板组切分 train/dev/internal-test，避免同模板跨集合泄漏。CosyVoice3 根据多名说话人参考生成不同速度的语音，SenseVoice 回译、CER、时长、静音率、削波率和声纹相似度共同决定样本是否进入训练。

## 2. ASR 课程增强

普通 ASR 只训练干净语音和无人声噪声增强语音，不用强重叠混合音频配目标文本训练。微调从 SenseVoice-Small 开始，冻结大部分 encoder，仅解冻最高三层和归一化层，使用小 batch、梯度累积和 FP16。

## 3. 重叠语音实验

以目标语音、不同说话人干扰和无人声噪声构造同起点混合信号，覆盖 TIR -10/-5/0/5 dB 和 SNR 15/20/25 dB。SepFormer 输出两路候选，ECAPA 比较唤醒参考与候选声道的说话人相似度，再在原音频、声道0和声道1之间选择识别候选。

## 4. 拒识策略

固定拒识由空文本、文本长度、训练域标签编辑相似度共同决定。阈值必须在开发集冻结，独立测试后不得反向调整。

## 5. 最终决策

合成增强 checkpoint 的直接 ASR 得到小幅提升，但分离、选择和固定拒识的组合在 datasetA 与 V3 上没有达到替换门槛。因此保留旧 BalancedReject 作为提交版，新链路作为实验复现与后续改进基础。
