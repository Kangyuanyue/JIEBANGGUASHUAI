## 六、已尝试方案与结论

| 方案 | 结果 | 原因 |
|------|------|------|
| noisereduce降噪 | CER升高 | 针对稳态噪声，对人声干扰无效 |
| DeepFilterNet降噪 | 效果不佳 | 同上，不适用于competing speech |
| 热词库后处理 | CER略升 | 阈值太宽松，把正确结果改错了 |

## 七、核心问题定位

**问题本质**：Competing Speech（竞争语音）

`cmd_2000+` 音频中混入新闻广播人声，与目标说话人声音大量时间重叠，SenseVoice 将背景声识别为主要内容。

**关键发现**：
- 干净音频CER约12%，模型本身识别能力尚可
- 带噪音频CER约72%，主要被竞争语音拖垮
- 拒识率表现较好
- 数据集问题：部分样本几乎全程声音重叠，缺少可分离片段

## 八、下一步方向（待实施）

### 目标说话人提取（Target Speaker Extraction）

**核心思路**：利用配对唤醒词音频（kws_*.wav）提取目标说话人声纹，引导从混合音频中提取目标声源。

**流程**：
```
kws_0.wav（唤醒词）→ 提取声纹embedding
         ↓
cmd_0.wav（混合音频）→ 目标说话人提取 → 干净指令音频
         ↓
SenseVoice 识别 → 文本结果
```

**推荐工具**：
```bash
pip install speechbrain asteroid
```

**声纹提取示例**：
```python
from speechbrain.inference.speaker import EncoderClassifier
import torchaudio, torch

classifier = EncoderClassifier.from_hparams(
    source="speechbrain/spkrec-ecapa-voxceleb",
    savedir="pretrained/ecapa"
)

def extract_embedding(wav_path):
    signal, fs = torchaudio.load(wav_path)
    return classifier.encode_batch(signal).squeeze()

emb_kws = extract_embedding("data/datasetA/pos/kws_0.wav")
emb_cmd = extract_embedding("data/datasetA/pos/cmd_0.wav")

similarity = torch.nn.functional.cosine_similarity(
    emb_kws.unsqueeze(0), emb_cmd.unsqueeze(0)
)
print(f"声纹相似度: {similarity.item():.4f}")
```

```python
import editdistance

def calc_cer(ref, hyp):
    ref = ref.replace(" ", "")
    hyp = hyp.replace(" ", "")
    dist = editdistance.eval(ref, hyp)
    return dist / max(len(ref), 1)
```
