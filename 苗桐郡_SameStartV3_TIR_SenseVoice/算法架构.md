# 算法架构

## 1. 可复现三路合成

输入为目标说话人语音、非目标说话人语音和无人声环境噪声。合成器先进行活动语音裁剪和 RMS 音量控制，再按照 TIR、SNR 和同起点规则对齐，最后统一限幅并保存 provenance。

POS 的唤醒人和命令目标人相同；NEG 的命令段由两名非唤醒人组成，标签为空。

## 2. 直接识别基线

混合命令音频直接进入 SenseVoice-Small。对 VAD 和 ITN 做单变量对照后，选择 no-VAD、关闭 ITN 作为 V3 全量基线。

## 3. 目标说话人候选路线

1. SepFormer 将混合命令分成两个候选声道。
2. ECAPA 分别提取干净唤醒词和候选声道的声纹向量。
3. 计算余弦相似度，选择与唤醒人最相似的候选声道。
4. 将候选声道送入 SenseVoice-Small。

该路线已经成功运行，但在配对小样本和 datasetA 全量上均使 CER 升高，因此作为失败对照保留。

## 4. 评价方法

- CER：正样本字符错误率，越低越好。
- RR：负样本拒识率，越高越好。
- 正样本误拒率：正确命令被拒绝的比例，越低越好。
- TIR 分层：分析目标人相对干扰人的强弱对 CER 的影响。

## 5. 设计结论

实验表明，环境噪声不是当前主要瓶颈。后续模型必须利用唤醒词提供的目标声纹，直接从混合语音中提取目标人；适合继续验证 VoiceFilter、SpEx+ 或 ClearerVoice TSE。
